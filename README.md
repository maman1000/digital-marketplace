# DibiTech - Marketplace Digital

DibiTech adalah platform marketplace digital yang mengkurasi berbagai alat bertenaga AI (kecerdasan buatan) untuk meningkatkan produktivitas, pemasaran, dan alur kerja kreatif. Proyek ini merupakan bagian dari portofolio pengembangan web yang menampilkan integrasi frontend modern dan desain responsif.

## ✨ Fitur Utama

- **Landing page** yang menarik dengan hero section dan navigasi yang jelas
- **Kategori produk** (Produktivitas, Pemasaran) dengan deskripsi singkat
- **Produk Unggulan** (Featured Product) menampilkan alat AI dengan rating tertinggi
- **Bagian Trending** untuk menampilkan alat AI populer (AI Writing Assistant, AI Image Generator)
- **Tombol navigasi** ke platform LMS (DibiEdu) sebagai proyek pendamping
- **Footer** berisi tautan informasi, media sosial, dan hak cipta

## 🛠️ Teknologi yang Digunakan

| Teknologi | Keterangan |
|-----------|-------------|
| HTML5 | Struktur halaman |
| CSS3 | Styling (file `style.css` dan `input.css`) |
| JavaScript | Interaktivitas (tombol navigasi) |
| Assets | Gambar dan ikon dalam format PNG/SVG |

> Catatan: Proyek ini masih menggunakan frontend statis. Backend dapat dikembangkan lebih lanjut (misalnya dengan Laravel + SQL seperti yang disebutkan di portofolio Anda).

## 🚀 Cara Menjalankan Proyek

1. **Clone atau unduh** repositori ini ke komputer Anda.
2. Pastikan struktur folder sebagai berikut:
   project-folder/
├── index.html (file utama)
├── style.css
├── input.css
├── assets/
│ ├── icon/
│ │ ├── kotak2.png
│ │ ├── productivity.png
│ │ ├── marketing.png
│ │ ├── twitter.svg
│ │ ├── instagram.svg
│ │ └── facebook.svg
│ └── images/
│ ├── featured-product.png

3. Buka file `index.html` menggunakan browser web modern (Chrome, Firefox, Edge).
4. Tidak diperlukan server web khusus karena ini halaman statis.

## 📂 Struktur Halaman

- **Navbar** : Logo, menu (Explore, Categories, Cart), tombol "Go to LMS" dan "LOGIN".
- **Hero** : Slogan "Discover the Future of Work with AI" dan deskripsi marketplace.
- **Categories** : Menampilkan dua kategori (Productivity, Marketing) dengan ikon dan deskripsi.
- **Featured Product** : Menyoroti satu produk unggulan dengan gambar dan tombol "Learn More".
- **Trending** : Dua produk trending (AI Writing Assistant, AI Image Generator).
- **Footer** : Tautan informasi, ikon media sosial, dan hak cipta.
